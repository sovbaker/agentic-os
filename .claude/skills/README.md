# Дизайн-скиллы

Сторонние наборы правил, по которым делается дизайн этого приложения.
Вендорим их в репозиторий намеренно: решения по интерфейсу должны быть
воспроизводимы, а Impeccable к тому же обращается к своим скриптам по
пути `.claude/skills/impeccable/scripts/...` внутри проекта.

| Скилл | Автор | Лицензия | Источник |
|---|---|---|---|
| `impeccable` | Paul Bakaus | Apache 2.0 | https://github.com/pbakaus/impeccable |
| `taste-skill` | Leon Lin (Leonxlnx) | MIT | https://github.com/Leonxlnx/taste-skill |
| `emil-design-eng`, `animate`, `review-animations` | Emil Kowalski | MIT | https://github.com/emilkowalski/skills |

Тексты лицензий лежат рядом с каждым скиллом.
