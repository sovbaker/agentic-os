## Суть за одну минуту

**Было:** ОС-ассистент, заменяющий все приложения; генерит мини-аппы под любую джобу; ведёт life graph; управляет облачным Android-эмулятором, включая банки и маркетплейсы; учится у пользователя.

**Стало после прожарки:**

> **Личный операционный директор твоей жизни.** Держит контекст, ведёт дела, делает рутину — и под каждую задачу собирает нужный интерфейс.

Конкурируем не с Ozon и не с ChatGPT, а с **хаосом по умолчанию**: заметки в трёх местах, скриншоты в галерее, 40 вкладок про ремонт и брошенная таблица.

### Что выжило

- Оркестратор, ведущий жизнь пользователя
- Life graph как system of record — настоящий ров
- Server-driven generated UI — но «генерим программу один раз», а не «кадр на каждый рендер»
- Мини-аппы как переиспользуемые артефакты — сходятся экономика, качество и рост
- Проактивность — то, чего нет у чат-ассистентов и что создаёт привычку
- Обучение у пользователя — но начиная с его решений внутри продукта

### Что вырезано из MVP

| Что | Почему |
|---|---|
| «Замена всех приложений» | приложение — это supply, а не интерфейс; тянет скоуп на каждом ревью |
| Эмулятор Android | Play Integrity, ToS, 152-ФЗ, экономика, риск App Store → research-трек за гейтом |
| Банковские приложения | в эмуляторе — **никогда** |
| Автономные действия без подтверждения | потолок MVP — «делает с подтверждением» |
| Генерация исполняемого кода | App Store 2.5.2 + безопасность |

### Восемь архитектурных решений

1. Expo + `expo-dev-client` (EAS) — **не** Expo Go: он не тянет кастомные нативные модули
2. Генерируем программу один раз, рендерим детерминированно (≤200 мс вместо 3–8 с)
3. UISpec: закрытый реестр компонентов, строгая схема, версии, repair loop, декларативные экшены
4. Задача — персистентный автомат (Postgres + очередь, Temporal при росте)
5. Life graph — Postgres + pgvector, с провенансом и битемпоральностью
6. Три памяти: эпизодическая / семантическая / **процедурная** (ров)
7. Безопасность по «правилу двух», изоляция недоверенного контента, человек в контуре на необратимом
8. Эмулятор — за гейтом; ADB + accessibility tree приоритетнее vision; финансы никогда

### Метрика №1

**TCFY** — задач, полностью закрытых *за* пользователя, в неделю. Цель: медиана ≥3 к 12-й неделе.
Метрика намеренно ломается, если продукт создаёт работу вместо того, чтобы её забирать.

## Принятые решения

| # | Решение |
|---|---|
| D1 | Рынок: **РФ первым**, глобал заложен в архитектуру через порты и адаптеры |
| D2 | Клин: **пять семейств задач** — поездки, здоровье, дом, документы, рутина |
| D3 | Эмулятор Android: **research-трек за гейтом**, в MVP — ассистированная передача |
| D4 | Ресурс: **один человек + AI-агент** → модульный монолит, урезанный скоуп |
| D5 | Потолок доверия в MVP: **делает с подтверждением** |

### Что из этого следует для плана

С AI-агентом объём кода перестаёт быть узким местом. Узкими становятся: **проверка правильности** (эвалы вместо код-ревью), **очередь решений из одного человека** и **внешний критический путь**, который не сжимается ничем — Apple Developer, ревью в App Store, набор беты.

Отдельная ловушка, обойдённая заранее: чтение Gmail — restricted scope со сторонним аудитом на недели и деньги. В MVP почта подключается через **адрес для пересылки**, календарь — через EventKit и CalDAV. Ноль верификаций, работает в день 1.

**Срок:** ≈6–8 недель сборки, **10–12 календарных недель** при полной занятости (×2.5–3, если вечерами).
