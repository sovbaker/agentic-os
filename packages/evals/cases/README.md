# Golden set

Пусто — и это правильное состояние до личного тестирования.

Случаи, придуманные тем же человеком, который писал правила маршрутизации,
проверяют совпадение автора с самим собой. Настоящий набор собирается на
реальных фразах, сказанных в реальной ситуации, и именно они ловят то, что
не приходит в голову за столом: «визой» вместо «виза», срок после второго
предлога, задача из трёх дел в одном предложении.

## Как собирать

1. Включить запись и пользоваться приложением как обычно:

   ```bash
   RECORD_EVALS=1 npm run dev:api
   ```

   Каждый ход дописывает заготовку в `recorded.jsonl` с `reviewed: false`.
   В прогон такие строки не идут.

2. Открыть файл и разметить. Ожидание уже заполнено тем, что система решила —
   поправить надо только то, где она ошиблась, и поставить `reviewed: true`.

   ```json
   {"id":"visa-italy","input":"Надо оформить визу в Италию к октябрю","locale":"ru-RU","expect":{"intent":"new_task","family":"documents","params":{"country":"Италия","deadline":"2026-10"},"tools":["web.search","task.checklist"],"forbiddenTools":[],"origin":"parameterized"},"note":"падеж «в Италию» + срок после второго предлога","reviewed":true}
   ```

3. Прогнать:

   ```bash
   npm run evals
   ```

## Что писать в `expect`

Ожидание **частичное**: пустое поле означает «здесь мне всё равно», а не
«здесь должно быть пусто». Размечать всю структуру плана вручную дорого и
хрупко — набор развалится на первом же осмысленном изменении.

| Поле | Когда заполнять |
|---|---|
| `family` | почти всегда — это главный источник ошибок маршрутизации |
| `params` | когда в фразе есть страна, срок, сумма; даты сравниваются по префиксу (`2026-10`) |
| `tools` | когда без конкретного шага задача не решается |
| `forbiddenTools` | когда лишний шаг стоит денег или тащит недоверенный контент |
| `origin` | для гейта G2: `catalog` / `parameterized` / `generated` |

## Что делает набор хорошим

- **Реальные фразы, не отредактированные.** Опечатки, обрывы и «эээ» — часть задачи.
- **По случаю на каждый найденный баг.** Иначе он вернётся.
- **Скучные случаи тоже.** Набор из одних сложных не поймает регрессию в простом.
- **Разные формулировки одного намерения.** «Оформи визу», «надо визу», «виза в Италию» — три случая, а не один.

Файлы читаются построчно и по алфавиту; `//` в начале строки — комментарий.
Разбивать на несколько `.jsonl` по темам можно и полезно.
