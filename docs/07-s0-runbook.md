# S0: как запустить и что уже работает

Спринт S0 из `06-roadmap.md`. Критерий приёмки — сквозной контур **«сказал → на телефоне серверный UISpec»** — выполнен.

---

## 1. Запуск

```bash
npm install

# Postgres 16. pgvector не обязателен: миграция 002 пропускается,
# семантический поиск деградирует до структурного (это штатное поведение).
createdb agentic_os
export DATABASE_URL="postgres://postgres@localhost:5432/agentic_os"
npm run db:migrate

npm run dev:api          # :8787
npm run dev:mobile       # Expo dev client
```

`ANTHROPIC_API_KEY` не обязателен. Без него оркестратор работает на детерминированном адаптере — весь контур поднимается офлайн, без ключей и расходов. Это не заглушка «пока не дошли руки»: на нём же гоняются тесты, и если сценарий сломался, виноват код вокруг модели, а не промпт.

**На устройстве** `localhost` недоступен — задай адрес машины в сети:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.10:8787 npm run dev:mobile
```

## 2. Проверка

```bash
npm run typecheck    # 4 пакета
npm test             # 26 тестов
npm run build:web && npm run verify:ui   # прогон в браузере со скриншотами
```

`verify:ui` поднимает собранный веб, прогоняет фразу → SSE → рендер → тап по чек-листу → действие на сервере, в светлой и тёмной теме, и падает при любой ошибке в консоли. Это дешёвая замена ручному прокликиванию и основа для скриншот-тестов реестра в S2.

| Слой | Состояние |

**Приёмка пройдена:** фраза «Надо оформить визу в Италию к октябрю, и я вечно про это забываю» → мини-аппа «Виза: Италия» со сроком «октябрь 2026», чек-листом из 6 пунктов и рабочими действиями. В графе — 5 фактов с провенансом.

## 4. Что нашлось при проверке

Три бага, все найдены прогоном, а не чтением кода:

1. **`\b` в JavaScript определена только по ASCII.** Все правила маршрутизации на русском молча не срабатывали: `/\bвиза/` не находит «визу» после пробела, потому что между двумя не-ASCII-символами границы слова не возникает. Внешне продукт работал — задача просто всегда уезжала в «other». Закрыто тестами.
2. **Разбор срока останавливался на первом предлоге.** В «визу в Италию к октябрю» первым совпадало «в Италию», и срок терялся целиком. Теперь перебираются все вхождения.
3. **«Виза в Италия».** В граф страна пишется в именительном падеже, а в заголовок попадала как есть. Согласование падежей убрано из формулировок вообще — «Виза: Италия» корректно для любой страны без словаря склонений.

Первый — ровно тот класс ошибок, ради которого в соло-режиме нужны тесты вместо код-ревью: он не виден при чтении и не ломает ничего заметно.

## 6. Единственное, что не проверено здесь

**Нативное распознавание речи.** Требует сборки на устройстве, которой в этом окружении нет. Веб-путь проверен полностью; нативный адаптер написан и целиком обёрнут в `try/catch` — при любой несовместимости голос деградирует до текстового ввода, а не роняет приложение.

Проверить при первой сборке dev client:

```bash
cd apps/mobile && npx expo install --check   # сверит версии с SDK 57
npx expo run:ios
```

`expo-speech-recognition` заявлен под SDK 56. Если сборка ругается — это одна строка в `package.json`, а приложение продолжит работать с текстовым вводом.
